# SPECTRUM S — Mining PvP MVP (Phaser 3)

Готовый минимальный шаблон игры под веб, без сборки (CDN), чтобы сразу залить в GitHub и включить GitHub Pages.

## Что внутри
- **Phaser 3** (через CDN) — никаких зависимостей и сборщиков.
- **PvP на 2 игрока**: P1 — WASD + SPACE; P2 — Arrows + RightCtrl.
- **Рудник** из разрушаемых блоков, выпадение кристаллов ✦.
- **Монстры**-слаймы, отнимают кристаллы при столкновении.
- **Таймер 3 минуты**, затем появляется **сундук** с бонусом, объявляется победитель.
- Всё отрисовано примитивами — можно заменить на ассеты позже.

## Локальный запуск
Откройте `index.html` просто в браузере или поднимите локальный сервер:
- Python: `python -m http.server 8080` и откройте http://localhost:8080

## Деплой в GitHub Pages
1. Создайте репозиторий и залейте файлы.
2. В настройках репо: **Settings → Pages** → Source: **Deploy from a branch**, Branch: `main` / `master`, Folder: `/root`.
3. Через минуту игра будет доступна по адресу GitHub Pages.
